# Ventaliance

Заказной лэндос для компании, занимающейся вентиляционными системами и кондиционированием.

## 🌐 Демо

https://katytrop.github.io/vent/

## 📁 Структура веток

- `main` — информация о проекте
  
- `dev` — основная ветка разработки
  Здесь находятся исходные файлы:  
  - SCSS  
  - JS (не сжатый)  
  - исходники
    
- `gh-pages` — собранная версия проекта  
  После сборки с помощью Gulp все стили, исходники и скрипты минифицированы.

## ⚙️ Технологии

- Gulp
- SCSS
- JavaScript (ES6+)
- BEM
- GSAP

## 🚀 Сборка и запуск

npm install     # Установка зависимостей
npm run dev     # Запуск проекта
